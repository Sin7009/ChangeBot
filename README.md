# ChangeBot

**ChangeBot** — это Telegram-бот, написанный на Python, предназначенный для автоматического обнаружения денежных сумм в сообщениях чата и их конвертации в другие валюты. Бот поддерживает работу как в группах, так и в инлайн-режиме.

Проект построен с использованием современного асинхронного стека технологий и готов к развертыванию через Docker.

## 🚀 Функциональность

*   **Автоматическая конвертация**: Бот "слушает" сообщения в чатах, находит суммы в одной валюте и предлагает перевод в целевые валюты.
*   **Распознавание изображений (OCR)**: Отправьте фото ценника или чека, и бот автоматически обнаружит сумму. Используется оптимизированный алгоритм для быстрого и точного распознавания. **Внимание:** для фото работает "строгий режим" — сумма должна содержать символ валюты (например, $, €, ₽, ₸), иначе она будет проигнорирована.
*   **Исторические графики**: Генерация графиков изменения курса валют за выбранный период (используются данные Yahoo Finance).
*   **Поддержка криптовалют**: Полная поддержка BTC, ETH, TON и USDT наряду с фиатными валютами.
*   **Инлайн-режим**: Возможность использовать бота в любом чате через `@botname` для быстрого расчета курсов (например, `@botname 100 USD`). В этом режиме конвертация всегда происходит в RUB, USD и EUR.
*   **Логирование**: Отправка логов в консоль для удобного мониторинга.

## 🕹 Команды

*   `/start` — Приветствие и краткая справка.
*   `/settings` — Настройка целевых валют для чата. Позволяет выбрать, в какие валюты конвертировать найденные суммы. (Примечание: нельзя отключить последнюю активную валюту).
*   `/chart <CODE>` — Генерация графика курса валюты к рублю за последний месяц.
    *   Пример: `/chart USD` покажет график USD/RUB.
    *   Пример: `/chart BTC` покажет график BTC/RUB.

## 🛠 Стек технологий

*   **Язык**: Python 3.12+
*   **Фреймворк бота**: [aiogram 3.x](https://github.com/aiogram/aiogram) — современный асинхронный фреймворк для Telegram Bot API.
*   **База данных**: SQLite (с драйвером aiosqlite).
*   **Провайдер курсов**: Yahoo Finance (через библиотеку yfinance).
*   **OCR**: Tesseract (pytesseract).
*   **Графики**: Matplotlib.
*   **ORM**: SQLAlchemy (асинхронная версия).
*   **Миграции**: Alembic.
*   **Конфигурация**: Pydantic Settings.
*   **Контейнеризация**: Docker & Docker Compose (с использованием uv для управления зависимостями).

## ⚙️ Установка и запуск

### Предварительные требования

*   Установленный [Docker](https://www.docker.com/) и Docker Compose.
*   Токен бота от [@BotFather](https://t.me/BotFather).

### Запуск через Docker (Рекомендуется)

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Sin7009/ChangeBot.git
    cd ChangeBot
    ```

2.  **Настройте окружение:**
    Создайте файл `.env` в корне проекта и заполните необходимые переменные.
    
    Пример `.env`:
    ```env
    BOT_TOKEN=ваш_токен_бота
    OER_API_KEY=any_value_here  # Обязателен для проверки конфига, но не используется провайдером
    LOG_LEVEL=INFO
    ```

3.  **Запустите контейнеры:**
    ```bash
    docker-compose up -d --build
    ```
    Это соберет образ, установит зависимости (включая Tesseract OCR) и запустит бота.

### Автодеплой на сервере

На сервере бот выкатывается сам после каждого мержа в `master`. Таймер `changebot-deploy.timer` раз в минуту запускает [deploy/deploy.sh](deploy/deploy.sh). Если в `origin/master` есть невыкаченный коммит, скрипт переключает отдельный чекаут `~/ChangeBot-deploy` на этот коммит и выполняет `docker compose up -d --build`. Рабочую копию для разработки он не трогает, она может стоять на любой ветке.

Установка:
```bash
git clone https://github.com/Sin7009/ChangeBot.git ~/ChangeBot-deploy
# .env, data/ и paddlex_cache/ лежат в основной папке, в чекаут деплоя они попадают симлинками
ln -s ~/ChangeBot/.env ~/ChangeBot/data ~/ChangeBot/paddlex_cache ~/ChangeBot-deploy/
cp ~/ChangeBot-deploy/deploy/changebot-deploy.{service,timer} ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now changebot-deploy.timer
```

Лог деплоев: `journalctl --user -u changebot-deploy`. Последний выкаченный коммит записан в `~/.local/state/changebot-deployed`. Если сборка упала, отметка не обновится, и следующий запуск таймера попробует снова.

### Локальный запуск (без Docker)

**Внимание**: Для работы функции OCR необходимо установить Tesseract в вашу систему.

1.  **Установите системные зависимости (Ubuntu/Debian):**
    ```bash
    sudo apt-get install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng libgl1-mesa-glx
    ```

2.  **Создайте виртуальное окружение:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # для Linux/macOS
    # .venv\Scripts\activate     # для Windows
    ```

3.  **Установите зависимости:**
    ```bash
    # Установка из pyproject.toml (рекомендуется)
    pip install .

    # ИЛИ через requirements.txt
    pip install -r requirements.txt
    ```

4.  **Настройте окружение:**
    Создайте файл `.env` (см. пример выше).

5.  **Примените миграции (если требуется):**
    ```bash
    alembic upgrade head
    ```

6.  **Запустите бота:**
    ```bash
    python main.py
    ```

## 🔧 Конфигурация

Настройки проекта управляются через переменные окружения (Environment Variables).

Основные параметры (проверьте `src/config.py` для полного списка):

| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `BOT_TOKEN` | Токен Telegram бота | **Обязательно** |
| `OER_API_KEY` | API ключ (заглушка) | **Обязательно** (любая строка) |
| `DB_PATH` | Путь к файлу SQLite | `bot_database.sqlite3` |
| `LOG_LEVEL` | Уровень логирования | `INFO` |

Для управления схемой базы данных используется **Alembic**.

*   **Создание новой миграции** (после изменения моделей):
    ```bash
    alembic revision --autogenerate -m "описание изменений"
    ```
*   **Применение миграций**:
    ```bash
    alembic upgrade head
    ```

## 🔒 Безопасность и надежность

Проект включает несколько уровней защиты и обработки ошибок:

*   **Валидация входных данных**: Все пользовательские входные данные проверяются и санитизируются
*   **Timeout protection**: Все внешние API вызовы имеют таймауты (30 секунд)
*   **Exponential backoff**: При сбоях API используется экспоненциальная задержка для предотвращения перегрузки
*   **Ограничение размера файлов**: Фотографии ограничены до 20MB
*   **Strict mode для OCR**: Режим строгой проверки требует наличия символов валют на изображениях
*   **Thread-safe кэширование**: Все операции с кэшем защищены от гонок потоков

Для управления зависимостями используется `uv` (в Docker) или стандартный `pip`.

### Запуск тестов

Проект включает комплексный набор тестов для обеспечения качества кода.

```bash
# Установка зависимостей для тестирования
pip install pytest pytest-asyncio

# Запуск всех тестов
pytest

# Запуск с подробным выводом
pytest -v

# Запуск конкретного модуля тестов
pytest tests/test_recognizer.py

# Запуск с покрытием кода (если установлен pytest-cov)
pytest --cov=src --cov-report=html
```

### Структура тестов

- `tests/test_recognizer.py` - основные тесты распознавания валют
- `tests/test_recognizer_edge_cases.py` - граничные случаи и валидация входных данных
- `tests/test_destructive_math.py` - тесты математической логики множителей
- `tests/test_destructive_parsing.py` - тесты парсинга чисел с запятыми
- `tests/test_rates.py` - тесты сервиса получения курсов валют
- `tests/test_ocr.py` - тесты распознавания текста на изображениях
