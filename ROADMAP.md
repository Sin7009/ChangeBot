# Roadmap

Порядок важен: пункты ниже опираются на предыдущие.

## 1. Хранение данных
- [x] SQLite-база в volume `./data` (`DB_PATH=/app/data/bot_database.sqlite3`). Раньше база жила в контейнере и обнулялась при каждой пересборке.

## 2. Прод = `master`
Сейчас на сервере крутится код из незакоммиченной рабочей копии.
- [x] Закоммитить переход на PaddleOCR (`ocr_service.py`, `Dockerfile.ocr`, клиент в `src/services/ocr.py`), фильтр фото в группах, разбор ценников.
- [x] Закоммитить запасной источник курсов ЦБ, сообщение «курсы недоступны», разбор столбика цен с ценника, volume для базы.
- [x] Убрать мусор из контекста сборки: `paddlex_cache/` в `.gitignore` и `.dockerignore`. Перенести `walkthrough.md` в `docs/`, а `inspect_paddleocr.py` в `scripts/`.

## 3. CI
- [x] Прогонять pytest на каждый pull request (сейчас workflow только собирает образ при пуше в `master`).

## 4. Курсы
- [x] Мелкие суммы в криптовалюте: 228 ₽ в BTC сейчас показывается как `0 BTC`. Нужны значащие цифры для сумм меньше 1.
- [x] Обновлять курсы фоновой задачей, а не по сообщению: пока Yahoo недоступен с сервера, раз в час одно сообщение ждёт ~10 с.
- [x] Сохранять последние курсы на диск, чтобы после перезапуска бот не стартовал без курсов.
- [x] Источник курсов криптовалют, доступный из РФ: у ЦБ их нет, а Yahoo периодически блокируется.

## 5. Деплой
- [ ] Один путь деплоя: либо сервер тянет образ, который CI публикует в ghcr.io, либо CI перестаёт его публиковать.
- [ ] Обновить токен ghcr.io в `~/.docker/config.json` (`gh auth token | docker login ghcr.io -u Sin7009 --password-stdin`).

## 6. Чистка и UX
- [ ] Убрать неиспользуемый `OER_API_KEY` из `src/config.py` (обязательное поле, остаток старого источника курсов).
- [ ] Убрать предупреждения yfinance: `TzCache` (`/root/.cache/py-yfinance`) и смену `auto_adjust` по умолчанию.
- [ ] Диапазоны одной строкой: «2.5–3 млн USD → …» вместо двух блоков.
